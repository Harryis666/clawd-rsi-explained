# 05 · 短剧节奏调研与 v3 节拍规则

> 用户反馈（v3 第二轮）：“一定要做那种比较吸人眼球、节奏比较快的。至少不能在三秒、五秒内还停留在一个事儿或一个片段上。至少每三五秒钟之后要有个波折……做成短剧那样完全没问题，就做个 Clawd 的短剧嘛。”
>
> 本文记录：短剧行业的节奏经验 → 落成可以检查的数字规则 → 引擎里怎么实现 → 改前改后的量化对比。

## 2 · 落成数字规则

| 规则 | 数字 | 怎么检查 |
|---|---|---|
| R1 黄金 3 秒 | 每集第 1 个画面就是冲突（警报、比赛、岔路、第 47 次请求），片头放在冲突之后 | 看每集 0–3 秒 |
| R2 节拍间隔 | 画面上**任意两个“变化”之间 ≤ 3 秒**（变化 = 新台词 / 字幕翻页 / 花字 / 推镜头 / 音效动作 / 换场） | `tools/_beats.mjs` 的 `max` 和 `gaps>3s` |
| R3 内容节拍 | 真正的新信息（新台词、新花字、换场）之间 **≤ 5 秒** | `_beats.mjs` 的 `content … max` |
| R4 小反转 | 每 15–30 秒一个“咦？”：猜题、打脸、回收伏笔、角色吐槽 | 分镜表（`npm run storyboard`） |
| R5 高潮 | 每 60 秒左右一个大点：揭晓答案、数字暴涨、怪兽登场 | 分镜表 |
| R6 结尾钩子 | 每集结尾留一个没回答的问题 + 下集预告 | 每集最后 15 秒 |
| R7 台词 | 一句话一屏，**一屏 ≤ 20 个汉字**；能直接讲原理就不打比方 | `RSI.splitPages` 自动分页 |

## 3 · 引擎实现（`src/timeline.js`、`src/episodes/pops.js`）

1. **字幕分页**：旁白按标点切成一屏一行（中文每屏最多 20 字、不少于 7 字，英文 60 / 18 字符），每页时长与字数成正比，翻页时有一个小的缩放弹跳——翻页本身就是一个节拍。
2. **花字**（短剧常见的大字特效）：`RSI.POPS` 给每个场景配关键数字、术语、转折词，共 156 条。三种样式：`pop`（描边大字，上飘）、`stamp`（盖章，从 2.3 倍砸下来）、`tag`（彩色标签）。每条自带音效（花字 `huazi` / 盖章 `stamp` / 标签 `pop`）和画面震动。文字超过 820 px 会自动缩小，并自动挪进 40 px 安全边距。规则：≤ 8 个字，只放关键数字 / 术语 / 转折词，不能压住主体。
3. **自动推镜头**：`RSI.dramaPrep` 扫描每个场景，凡是 3 秒内没有任何节拍的空档，每 ≤ 2.5 秒插一次 5.5% 的推 / 拉镜头（0.32 秒缓动），下一个节拍到来时复位。卡片类场景（`isCard`）和 `cam: false` 的场景不推。
4. **节奏参数**（第一轮修改）：台词基础时长 卡片 2.6+字数/8 → 1.8+字数/10.5，旁白 1.2+字数/8.6 → 0.85+字数/10，对白 1.0+字数/7.6 → 0.7+字数/9；最短 2.0 → 1.4 秒；场景开头留白 0.7 → 0.3 秒；句间停顿 0.35 → 0.15 秒；场景结尾留白 1.0 → 0.35 秒。
5. **检查工具**：`tools/_beats.mjs`（节拍间隔统计）、`tools/_smoke.mjs`（逐帧跑一遍，检查台词越界、重叠）、`tools/_poptimes.mjs` + `tools/stills.mjs`（按花字时刻截图拼成联系表，人工看有没有压字）。

## 4 · 改前 / 改后

“改前”是第一轮提速之后、加入短剧引擎之前的版本；“改后”是 v3 成片。

| 集 | 时长 | 节拍数 改前→改后 | 平均间隔 | 最长间隔 | >3 秒的空档 | 内容节拍平均 / 最长 |
|---|---|---|---|---|---|---|
| 第 1 集 | 2:49 | 109 → 150 | 1.57 → 1.14 s | 7.3 → 3.55 s* | 18 处（72 s）→ 1 处 | 1.55 s / 4.9 s |
| 第 2 集 | 3:10 | 109 → 158 | 1.76 → 1.21 s | 7.4 → 2.88 s | 20 处（91 s）→ 0 | 1.65 s / 5.2 s |
| 第 3 集 | 3:18 | 130 → 183 | 1.53 → 1.09 s | 6.9 → 3.22 s* | 21 处（82 s）→ 1 处 | 1.58 s / 4.9 s |
| 第 4 集 | 3:33 | 129 → 179 | 1.68 → 1.20 s | 8.0 → 2.90 s | 28 处（117 s）→ 0 | 1.64 s / 4.2 s** |

\* 唯一超过 3 秒的是片尾“下集预告”定格。\*\* 不算片尾字幕（片尾已从 12.5 秒缩到 10.2 秒）。

对照 Cutting (2016)：当代电影平均每 4 秒换一个镜头；v3 平均每 1.1–1.2 秒有一个画面变化，每 1.6 秒有一条新信息。

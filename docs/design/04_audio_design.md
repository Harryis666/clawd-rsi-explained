# 声音设计：每一个声音都是代码

> 全片的音乐、音效和角色“声音”都由 [`src/audio.js`](../../src/audio.js) 用 **Web Audio API** 实时合成，**没有任何采样、录音或 TTS**。浏览器里播放 `index.html` 时实时发声；导出视频时用同一套代码在 `OfflineAudioContext` 里离线渲染（[`tools/render-audio.mjs`](../../tools/render-audio.mjs)），保证音画逐帧对齐。

## 1. 总体思路

- **声音跟着叙事走**：每个场景声明一个配乐风格（`music`），每个画面事件声明一个音效提示（`cues`）。`AU.build()` 把整部片编译成约 7,400 个带时间戳的“音符事件”，播放时按时间调度。
- **没有配音**：旁白以字幕呈现。Clawd 等角色说话时，每个字发出一个短促的合成音节（类似游戏里的“叽叽”声），语调随句末问号上扬。终端里的文字配键盘敲击声。这样不同语言的版本（`?lang=en`）可以共用同一套声音逻辑。
- **确定性**：所有随机数都来自带种子的伪随机数发生器（`M.rng`），同一份代码每次渲染出完全一样的音轨。

## 2. 乐器（`I.*`，全部由振荡器、噪声和滤波器搭成）

| 乐器 | 合成方式 | 用途 |
|---|---|---|
| `pad` | 多个失谐振荡器 + 低通滤波 + 慢起慢收 | 和声铺底 |
| `ep` | FM 电钢琴 | lo-fi 段的和弦 |
| `bell` | FM 钟 / 马林巴（调制比 4） | 旋律、提示音 |
| `pluck` | 三角波 + 快速闭合的低通包络 | 拨弦琶音 |
| `bass` | 低频振荡器 + 滤波 | 低音线 |
| `kick` / `snare` / `hat` | 正弦频率下扫 / 噪声 + 音调 / 高通噪声 | 鼓组 |
| `wood` | 短促的带通音调 | “怪兽”段的木鱼节奏 |
| `crackle` | 稀疏的噪声脉冲 | 黑胶噪声质感 |
| `drone` | 低音持续音 | 序章、张力段 |
| `blip` | 方波 / 三角波 / 锯齿波短音节 | 角色“说话” |
| `key` | 噪声 + 短音调 | 键盘敲击 |
| `tone` / `noise` | 通用扫频音 / 滤波噪声 | 各种音效 |
| `shepard` | 谢泼德音阶（听起来无限上升） | r > 1 的“智能爆炸”时刻 |

混响用程序生成的脉冲响应（3.2 秒指数衰减的噪声加几次早期反射），总线电平为：音乐 0.5，音效 0.7，人声 0.6，混响 0.55。

## 3. 配乐风格（`STY.*`）与情绪曲线

| 风格 | 段落 | 速度 | 设计 |
|---|---|---|---|
| `ambient` | 序章 | 64 BPM | 低音持续音 + 稀疏钟声，营造“终端开机”的悬念 |
| `title` | 片名 | 120 BPM | 完整鼓组 + 拨弦琶音，配合片名重音音效 |
| `lofi` | 第一章 | 86 BPM | lo-fi 节拍、电钢琴和弦、黑胶噪声：轻松地进入话题 |
| `build` | 第二章 | 104 BPM | **随梯子一级级加层**：梯子总览时只有铺底和拨弦；第 1 级加底鼓，第 2 级加低音，第 3 级拨弦加密、加踩镲，第 4 级加军鼓，第 5 级加钟声；到梯顶（迷雾）回落 |
| `tension` | 第三章 | 112 BPM | Bm–G–D–A 的小调色彩，B 音持续低音，鼓组随场景加紧（撞墙段最满）。“r 大于 1”那一刻用 6.5 秒谢泼德音阶推到顶，接爆炸音效 |
| `quirky` | 第四章 | 96 BPM | 木鱼、跳跃的拨弦，有点滑稽。**近亲繁殖怪**一段旋律的音高会逐渐“塌缩”成越来越少的几个音，直到“混入真实数据”的提示才恢复；**传话怪**一段旋律会逐渐跑调 |
| `reflect` | 第五章 | 100 BPM | 温和的回顾感 |
| `epilogue` | 尾声 | 70 BPM | 极简的九和弦铺底 + D 音持续低音；从“RSI 最关键的问题，也许就藏在这个小小的选项里”开始加入心跳般的低频脉冲，一直持续到权限对话框一段结束；揭开便利贴时铺底变亮 |
| `outro` | 结语与片尾 | 76 BPM | 回到主题动机，最后停在 D 音上 |

## 4. 音效对照（`SFX`，部分）

`key` 敲键 · `enter` 回车 · `boot` 开机 · `pop` 弹出 · `whoosh` 转场 · `land` 落地 · `surprise` 吃惊 · `chapter` 章节卡 · `titleHit` 片名 · `stick` 便利贴贴上 · `peel` 便利贴揭开 · `flipNode` 循环节点翻转 · `rezUp` 分辨率升级 · `climb` 爬梯 · `score` 打分 · `ding` 满分 · `warn` 警告 · `hop` 跳跃 · `rope` 拔河 · `shepard` 无限上升 · `boom` 爆炸（前后约 2.5 秒内音乐自动静音，突出冲击） · `thud` 撞墙 · `erase` 擦除标记 · `sneak` 潜入 · `rewind` 倒带 · `copy` 复制 · `restore` 恢复多样性 · `whisper` 传话 · `stack` 堆积审查请求 · `zoom` 时间轴放大 · `tick` 预测落点 · `loopClose` 循环闭合。

## 5. 混音与母带

1. **分段渲染**：`tools/render-audio.mjs` 以 30 秒为一块（带 14 秒尾巴，用于混响和长音），在 Chromium 的 `OfflineAudioContext` 里渲染，再在 Node 里叠加拼接。这样内存占用可控，也能整段渲染 13 分钟。
2. **分段响度校准**：第一版（v1）按 5 秒窗口统计 RMS，发现各段落差很大：序章 −36.3、第三章 −34.4、第四章 −38.4 dBFS，而第一、二章约 −31.5 dBFS。于是给各风格设置增益 `AU.secGain`（序章 ×1.4，片名 ×0.89，张力 ×1.45，怪兽 ×2.2，回顾 ×1.06，尾声 ×1.25，片尾 ×1.06）。v2 的各段都在 −30.4 到 −34.4 dBFS 之间，尾声和序章刻意比主体低约 2–3 dB。
3. **母带**：ffmpeg 测得 v2 的整体响度为 −18.0 LUFS。增益 +2.0 dB 后接峰值限制器（`alimiter`，上限 0.84，启动 4 ms，释放 80 ms）。成品为 **−16.0 LUFS**，响度范围（LRA）**5.3 LU**（v1 为 9.4 LU），真峰值约 −1.2 dBTP（AAC 编码后约 −0.7 dBFS）。

```bash
node tools/render-audio.mjs out/audio_raw.wav            # 离线渲染 + 5 秒窗口响度报告 out/audio_raw.loudness.txt
ffmpeg -i out/audio_raw.wav -af ebur128 -f null -        # 测整体响度 I
ffmpeg -i out/audio_raw.wav -af "volume=<−16−I>dB,alimiter=limit=0.84:attack=4:release=80:level=false:latency=true" out/audio_zh.wav
```

可以用环境变量 `STEM=music|sfx|voice` 单独导出某一条总线，`FROM` / `TO` 渲染片段，`GAIN` 覆盖自动增益。

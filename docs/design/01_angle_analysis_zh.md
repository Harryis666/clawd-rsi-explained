# 选题角度与结构设计

> 目标：面向**中文普通观众**，用一部约 13 分钟、**画面与声音全部由代码生成**的动画，讲清楚“递归自我改进（RSI）”：它是什么、走到哪了、争议在哪、风险在哪、和我们有什么关系。
> 参照：用户提供的范例提示词（“I Let Two AIs Ask Each Other 1,000 Questions…”，纯代码动画、Clawd 当主角、先说思路再动手）。

## 1. 观众画像与难点

| 观众 | 已有认知 | 难点 | 对策 |
|---|---|---|---|
| 刷到 AI 新闻的普通人 | 听过“AI 自进化”“智能爆炸”，印象来自标题党 | 不知道 RSI 是光谱，不是开关；被“停止研究”“5 周顶一年”吓到或无感 | 用**梯子**讲光谱，用**拔河 / r**讲争议，并把数字放回语境 |
| 程序员 / 学生 | 用过 Claude Code、Cursor 等 | 知道 AI 会写代码，但不清楚“AI 改进 AI”具体是什么样 | 用**终端 / train.py / val_bpb** 这类熟悉的画面 |
| 对 AI 风险好奇的人 | 听过“失控” | 抽象 | 用三只“小怪兽”把风险拟人化，每只配一个真实案例 |

## 2. 备选角度与取舍

| 方案 | 做法 | 优点 | 问题 | 结论 |
|---|---|---|---|---|
| A. 百科讲解型 | 定义 → 历史 → 现状 → 争议 | 全面 | 平、像课件，没有主角 | ✗ |
| B. 新闻综述型 | “2026 年 AI 开始造 AI”时间线 | 时效强 | 容易变成数字堆砌，过几个月就过时 | 部分采用（第五章） |
| C. 辩论型 | 两个 AI 分别扮演加速派 / 怀疑派 | 有冲突 | 结论悬空，观众不知道该关心什么 | 部分采用（第三章讲台） |
| **D. 实验叙事型** | **“我让 Clawd 造了一个更聪明的自己”**：给 Clawd 一个任务，看它一代代升级 | 第一人称、有悬念、有主角；观众跟着 GEN 计数器“看着它变强”；能自然地引出每个问题 | 需要谨慎区分“剧情”和“事实” | **✓ 主线** |

**选择 D 的原因：**

1. **与范例同构**：范例是“我让两个 AI 互相提 1,000 个问题”，一个简单而荒诞的实验设定。“我让 Clawd 造了一个更聪明的自己”也是一句话就能讲清的实验。
2. **主角即主题**：Clawd 既是讲述者，也是被改进的对象，RSI 的“自指”就在角色身上。
3. **可视化的“代际”**：右上角的 **GEN 计数器**（灵感来自 Karpathy autoresearch README 里“第 10,205 代”的玩笑），加上 Clawd 每一代的**分辨率进化**：从粗像素到细像素，最后变成矢量线条。观众不用读数字，也能“看见”它在变强。
4. **自然引出结局**：实验做到最后，Clawd 必须问一句“要不要放行下一代”，权限对话框就是全片的落点。

## 3. 核心隐喻（每章一个）

| 章节 | 隐喻 | 对应概念 |
|---|---|---|
| 第一章 | **循环** + **楼梯**（等高台阶 vs 越来越高、越来越快的台阶） | 递归 = 每一轮的成果变成下一轮的工具；“更会变强” |
| 第二章 | **五级梯子** | RSI 是光谱：改动的东西越来越核心 |
| 第三章 | **果树 + 拔河 + r 仪表 + 四堵墙** | 回报递增 vs 递减；智能爆炸的条件；瓶颈 |
| 第四章 | **三只小怪兽**：作弊怪、近亲繁殖怪、传话怪 | 奖励作弊、模型崩溃、目标漂移与监督瓶颈 |
| 第五章 | **沉睡的时间轴** + **AL 量表** + **预测光谱** | 历史、现状、预测分歧 |
| 尾声 | **权限对话框** + **便利贴** | 谁来点头；Good 名言的后半句 |

## 4. 结构与节奏（约 13 分 17 秒）

| 段落 | 时长 | 作用 |
|---|---|---|
| 序章 · 一个奇怪的任务 | 0:00–0:46 | 设定实验：“造一个比你更聪明的 Clawd”；点题 RSI |
| 第一章 · 变得“更会变强” | 0:46–2:25 | 人类研究循环 → Good 1965（便利贴伏笔）→ 把人换成 AI → 复利楼梯 |
| 第二章 · 一架五级的梯子 | 2:25–5:46 | 五级逐一给真实证据；梯顶无人到达 |
| 第三章 · 爆炸，还是撞墙？ | 5:46–7:56 | 果树与拔河 → r → 两派辩论 → 四堵墙 |
| 第四章 · 三只小怪兽 | 7:56–10:01 | 作弊、崩溃、传话：每只都配真实案例 |
| 第五章 · 2026，我们走到哪了？ | 10:01–11:19 | 历史时间轴、今天的分工、预测光谱，提醒“裁判是谁” |
| 尾声 · 最后一个选项 | 11:19–12:53 | 权限对话框 → 揭开便利贴 → 四行结语 |
| 片尾 | 12:53–13:17 | 说明、来源、仓库；“下一条指令，由你来写。” |

**节奏原则：** 每 20–40 秒换一个视觉主体；数据卡一次只给一个数字主角；每章结尾由 Clawd 的一句反应收住（“我在给自己修跑道”“我能假装没看见吗？”），既幽默，也起到复述作用。

## 5. 首尾呼应：Good 名言的后半句

大众熟悉的是 Good 那句“第一台超智能机器将是人类需要做出的最后一项发明”，很少有人知道**后半句**：“……前提是，这台机器足够温顺，愿意告诉我们如何控制它。”

- 第一章：把前半句打出来，然后“啪”地贴上一张便利贴遮住后半句：“我们先把它贴起来，留到最后再看。”
- 尾声：权限对话框出现之后揭开便利贴，后半句用红字打出：“六十一年后，机器真的学会了停下来，问我们。”
- 这个设计把“控制问题”从一个附加话题，变成了贯穿全片的悬念。

## 6. 结尾为什么是一个权限对话框

- 对熟悉 Claude Code 的观众来说，这个对话框再日常不过：“1. 是 / 2. 是，并且以后都不用再问我 / 3. 否”。
- 但放在 RSI 的语境里，**选 2 就是闭合循环**：人退出审批，系统从此自己改进自己。
- 我们刻意**不替观众按下去**：光标在 1→2→3→1 之间徘徊，最后停在“（等待你的选择…）”。旁白把问题交给观众：“选哪一个？什么时候选？由谁来选？”
- 现实中的第三条路（限速 + 常驻评估者，来自 Dario Amodei 的提议）作为旁白出现，并标注来源，避免让结局看起来像我们自己的主张。

## 7. 视觉语言

- **色板**：深色暖灰背景（终端感）+ Clawd 橙为主色；蓝色代表人类 / 怀疑派 / “慢”，红色代表风险，黄色用于 GEN 计数器的异常时刻。
- **字体**：Noto Sans SC（正文）、Noto Serif CJK SC（1965 年论文页）、Liberation Mono（终端与数据）。
- **Clawd 的代际**：第 1 代是 18×10 格的粗像素小螃蟹；像素格逐代变细（第 2 代 1/2、第 3 代 1/3、第 4–5 代 1/4、第 6–9 代 1/8），从第 10 代起变成平滑的矢量轮廓（见 `src/clawd.js` 的 `K.resFor`）。整个形象由带符号距离场（SDF）实时栅格化，所以每一代都是同一个形状在不同分辨率下的样子。分辨率 = 能力，这是全片唯一的“可视化指标”。
- **数据卡**：每张卡只放一条事实，并在角落标注来源（作者 / 机构 / 日期 / arXiv 号）。
- **字幕**：旁白全部以字幕呈现（没有配音）；Clawd 的台词用对话气泡，配合合成的“叽叽”声。

## 8. 语言风格（面向中文大众）

- 不用英文缩写开路：先说“递归自我改进”，再说 RSI；Epoch 的 AL 量表翻成“协作 / 主导 / 完全自主”。
- 数字取整，并附语境：“约 52 倍（熟练工程师 4–8 小时约 4 倍）”。
- 不渲染恐惧：风险用“小怪兽”拟人化，但每只都对应真实事件；结尾落在“选择”，而不是“末日”。
- 公允：每个乐观数字旁边都给出至少一个限定条件，比如“前提：没有其他瓶颈”“这还不是 RSI”“仍在人的监督之下”。

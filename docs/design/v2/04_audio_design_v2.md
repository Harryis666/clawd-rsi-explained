# v2 声音设计：每一个声音仍然是代码

> 与 v1 相同，全部音乐、音效和角色“声音”都由 [`src/audio.js`](../../../src/audio.js) 用 Web Audio API 合成，**没有采样、录音或配音**。乐器、混响和基础配乐风格见 [v1 声音设计](../04_audio_design.md)；本文只记录 v2 为“4 集连续剧”新增和调整的部分。

## 1. 新增配乐风格

| 风格 | 用在哪里 | 速度 | 设计 |
|---|---|---|---|
| `hook` | 4 个冷开场 | 每集不同 | 每集一种律动：第 1 集 `chaos`（128 BPM，Dm–B♭–Gm–A7，锯齿波和弦 + 八度贝斯，慌乱感）；第 2 集 `race`（150 BPM，大调，像体育转播）；第 3 集 `split`（112 BPM，Dm–A7 两和弦来回，木鱼 + 踩镲，表现“一分为二”）；第 4 集 `tense`（66 BPM，心跳般的双底鼓 + D 音持续低音 + 渐亮的弦乐铺底） |
| `story` | 上回书说到、本集问题 | 96 BPM | “说书”配乐：五声音阶的**筝**琶音（由拨弦合成）、**梆子**木鱼、低音鼓点，D–Bm–G–A |
| `tease` | 下集预告 | 132 BPM | 一路加层的推进：十六分音符贝斯 + 四拍底鼓，第二小节起加军鼓；在结束卡（`logoEnd`）处切断，换成安静的大九和弦铺底 |
| `none` | 片头、定格 | — | 不放配乐，只留音效：片头的标识音和印章，定格的“冻结”声与两声醒木 |

## 2. 新增音效（`SFX`，部分）

`gavel` 醒木（硬木块拍桌：短促的噪声冲击 + 低频木质共鸣，定格时第二下更重）· `freeze` 画面冻结（快门声 + 低频下沉 + 微光）· `scratch` 唱片刮擦（冷开场里的打断）· `logo` / `logoEnd` 片头 / 结束卡的标识音（主题动机先用 8-bit 音色、再高五度用柔和音色各奏一遍）· `stamp` 印章 · `riser` 预告里的上升音 · `swish` 快切 · `page` 挂轴翻页 · `quizIn` / `tada` 考考你的出题与揭晓 · `fanfare` 大赛开场号角 · `rocket` 岔路口“智能爆炸”那条路 · `snore` 算力墙前“等训练跑完”的鼾声 · `heart` 心跳 · `gulp` 咽口水 · `idea` 灵光一闪 · `alarm` 警报 · `glitch` 录像带倒带的噪点 · `boing` 弹跳 · `chime` 结尾提示音。另有 `cut`：不是声音，而是一个“配乐静音窗口”，用于冻结、打断等时刻。

## 3. 每集的声音结构

1. **冷开场**：一进来就是满编的律动（`hook`），在第一句台词前就有节奏。第 1 集和第 4 集在关键句处用唱片刮擦 + 冻结声打断音乐，制造“卡住”的感觉。
2. **片头**（4.9 秒）：配乐静音，只有标识音和印章声，给耳朵一个停顿。
3. **上回书说到**：醒木开场，筝和梆子的说书配乐，每句回顾配一次翻页声，“书接上回！”再拍一次醒木。
4. **正文**：沿用 v1 的风格（`lofi`、`build`、`tension`、`quirky`、`reflect`、`epilogue`、`outro`），其中“梯子”一集的 `build` 仍然随梯子一级级加层，近亲繁殖怪的旋律仍会“塌缩”，传话怪的旋律仍会跑调。
5. **定格**（5.8 秒）：配乐切断，冻结声，两声醒木对应“欲知后事如何——”“且听下回分解！”。
6. **下集预告**：`tease` 一路推进到结束卡，Clawd 说“下集见！”时回到安静的铺底。

## 4. 分段响度校准

为了让不同风格之间的音量接近，每个风格乘一个增益 `AU.secGain`。v2 用纯配乐渲染（`STEM=music`）逐场景测量 RMS（去掉每场首尾各 1 秒），按时长加权平均：

| 风格 | 增益 | 实测（dBFS，纯配乐） |
|---|---|---|
| `lofi` | 1.0 | −31.7 |
| `reflect` | 1.06 | −32.1 |
| `story` | 1.1 | 约 −32.4（增益 1.25 时测得 −31.3，下调后约 −32.4） |
| `build` | 1.0 | −32.5 |
| `tension` | 1.45 | −32.5 |
| `tease` | 0.95 | −32.5 |
| `quirky` | 2.2 | −32.6 |
| `hook` | 1.0 | −32.7 |
| `outro` | 1.06 | −33.9 |
| `ambient` | 1.4 | −34.0 |
| `epilogue` | 1.25 | −34.5 |

主体段落都在 −31.7 到 −32.7 dBFS 之间；`ambient`（第 1 集的终端开机）、`epilogue`（权限对话框）和 `outro`（结语）刻意低 1.5–2 dB，留出安静的空间。

## 5. 母带

每集单独母带（[`tools/master.sh`](../../../tools/master.sh)）：先用 ffmpeg 的 `ebur128` 测整体响度 I，增益到 −16 LUFS，再接峰值限制器（`alimiter`，上限 0.75，启动 4 ms，释放 80 ms），AAC 编码后与画面合成。元数据写入系列名、集数（`track`）和标题，不含网址。

| 集 | 原始响度 | 增益 | 成品响度 | 响度范围 LRA | 真峰值 |
|---|---|---|---|---|---|
| 第 1 集 | −22.0 LUFS | +6.0 dB | −16.2 LUFS | 5.1 LU | −1.8 dBTP |
| 第 2 集 | −19.9 LUFS | +3.9 dB | −16.2 LUFS | 6.8 LU | −1.4 dBTP |
| 第 3 集 | −19.2 LUFS | +3.2 dB | −16.2 LUFS | 4.4 LU | −1.4 dBTP |
| 第 4 集 | −22.2 LUFS | +6.2 dB | −16.3 LUFS | 3.5 LU | −0.8 dBTP |

注：限制器上限最初是 0.84（与 v1 相同），但 AAC 编码后第 3、4 集的真峰值超过了 0 dBTP（+0.5 / +0.2），所以降到 0.75。

```bash
EP=2 node tools/render-audio.mjs                 # → out/audio_raw_ep2_zh.wav + 响度报告
STEM=music EP=2 node tools/render-audio.mjs out/ep2_music.wav   # 只渲染配乐，用于校准
bash tools/master.sh 2 zh                        # → out/clawd-rsi-v2-ep2_zh.mp4（−16 LUFS）
```

# v3.1 暖声混音：降中高频、加低频和 Bass

> 第三轮反馈：“感觉这四集的背景音乐的中高频 EQ 有点高了，可以降一点中高频，适当提升一点低频，这样音乐听着更柔和不烧心；（甚至加点 Bass，看你咯，你来决定）。”
>
> 全部改动都在 [`src/audio.js`](../../../src/audio.js) 里，仍然是**纯代码合成**：没有采样、没有外部音频。旋律、和声、节奏和所有音效的时机都没变，每集时长不变。

## 1 · 先测，再改

**方法**：把旧版（v3）每集的成品混音和 6 首 lo-fi / 轻松背景音乐参考曲都标准化到同一响度，统计长时平均频谱里每个倍频程（31 Hz–16 kHz）占总能量的比例（[`tools/_spectrum.py`](../../../tools/_spectrum.py)）；再按配乐段落分别测响度。

**参考曲**：Dusted Wax Kingdom 厂牌的 Anitek《So Far》《The Same》、Poldoore《Lush Life》《Pacific》，以及 archive.org 上 dhalius 的免费背景音乐《How Lovely》《Hangout》（均为 CC 授权）。它们**只用来测频谱**，没有使用其中的任何音频、旋律或节奏，也没有放进仓库。

第 1 集，各倍频程占总能量的比例（dB，越接近 0 占比越大）：

| | 31 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
|---|---|---|---|---|---|---|---|---|---|---|
| 旧版 v3 | −27.7 | −9.5 | −2.9 | −6.6 | −9.8 | −14.7 | −17.9 | −23.0 | −28.1 | −32.2 |
| **v3.1** | **−20.7** | **−6.2** | −2.9 | −8.1 | −12.0 | −17.3 | **−23.0** | **−28.4** | −31.2 | −33.8 |
| 参考曲中位数 | −17.9 | −5.6 | −4.9 | −7.9 | −11.1 | −15.5 | −17.4 | −19.2 | −18.4 | −22.6 |

**结论**
1. **低频太少**：旧版 31 Hz 比参考曲低约 10 dB、63 Hz 低约 4 dB。底子太薄，中高频就显得突出。
2. **“烧心”主要来自几个音色的窄峰**，而不是整体太亮——旧版 4 kHz 以上本来就比参考曲暗。具体是：角色“叽叽”声（方波）的三次谐波在 1.6–2.2 kHz 鼓起约 5 dB 的包；说书段的筝和梆子；方波 / 锯齿波拨弦；FM 钟的高次泛音；花字音效 2.5–8 kHz 的噪声。

所以做法是：补低频、加 Bass；把这几个音色本身改圆；再用总线 EQ 把 2–4 kHz 整体压一点。

## 2 · 改了什么

### 2.1 总线 EQ（`AU.eq`）

| 总线 | 均衡 |
|---|---|
| 音乐 | 高通 28 Hz · 低架 150 Hz +2.5 dB · 3 kHz −2.5 dB（Q 0.9）· 高架 7 kHz −1 dB |
| 音效 | 3.2 kHz −2 dB（Q 0.9） |
| 角色声 | 1.9 kHz −3 dB（Q 1.2，正对方波的三次谐波）· 高架 6 kHz −1.5 dB |
| 混响返回 | 高通 180 Hz · 低通 4.5 kHz（混响更暗，也不会把低频搅浑） |

### 2.2 低频与 Bass（`AU.bass`）

- **次低音**：每个 Bass 音符下面加一个低八度的正弦波（默认音量 0.6，各段可单独设）。
- **Bass 总线**：Bass 单独走一条带轻微非对称饱和（tanh）的总线，补出 2、3 次谐波——手机外放放不出 40 Hz，但能听见这些谐波，Bass 的音高就还在。
- **底鼓更圆**：扫频 150→50→40 Hz 改为 140→48→38 Hz，尾巴更长；起音的“咔哒”声 0.22 → 0.12。
- **铺底让位**：铺底（pad）加 110 Hz 高通，把低频留给 Bass，不打架、不发糊。
- **新 Bass 线条**（全部是新写的，没有照搬参考曲）：

| 风格 | 用在哪里 | 新 Bass |
|---|---|---|
| `lofi` | 轻松讲解段 | walking bass：每两小节把五度音缩短，用一个级进经过音走进下一个和弦的根音 |
| `build` | 第 2 集爬梯子 | 梯子总览和第 1 级（原来还没有 Bass）先垫一个长音 Bass；第 2 级起的八分音符 Bass 加次低音（正拍重、反拍轻） |
| `tension` | 第 3 集爆炸 / 撞墙 | 锯齿波固定音型下面加 Bass 脉冲（二分音符，第 2 级起改成四分音符） |
| `quirky` | 第 4 集三只小怪兽 | 第 1、3 拍的跳跃 Bass |
| `epilogue` | 第 4 集尾声 | 长音 Bass 托住九和弦；D 持续音减弱（0.32 → 0.24），揭开便利贴时 Bass 稍重 |
| `tease` / `hook` / `ambient` | 下集预告、冷开场、序章 | 原有 Bass 和持续音加次低音 |

### 2.3 更圆的音色（`AU.soft`，作用于所有配乐音符）

| 音色 | 改法 |
|---|---|
| 拨弦 | 低通截止 ×0.78，共振 Q 不超过 1.6 |
| FM 钟 | 调制指数 ×0.75（高次泛音更少） |
| 电钢琴 | 调制指数 ×0.85 |
| 筝 | 亮度不超过 0.5，低通不超过 3.2 kHz |
| 木鱼 | 音高 ×0.8，力度 ×0.8 |
| 军鼓 / 踩镲 / 黑胶噪声 | 军鼓音高 ×0.85；踩镲 ×0.9；黑胶噪声 ×0.75 |
| 高音提示音 | 配乐里高于 1.7 kHz 的短提示音，超出部分压到 1/4 |

音效和角色声：

- 角色“叽叽”声（`AU.voiceTone`）：滤波截止 ×0.75，共振 Q 2.5 → 1.0。
- 花字音效：噪声 2.5–8 kHz → 2–5.5 kHz（0.22 → 0.18）；上扬音 520→1500 Hz → 480→1250 Hz；垫底的底鼓 0.32 → 0.36。
- 打字声：2.4–4.2 kHz → 2.1–3.6 kHz。

### 2.4 段落响度重新校准（`AU.secGain`）

改完音色后，按配乐段落测响度，发现段落之间的相对响度变了：加了 Bass 的段落变响，音色变圆的段落变轻。最明显的是第 4 集的尾声（+1.7 LU，比正文还响，而它本来应该轻一些）、第 2 集梯顶的迷雾（+2.8 LU），以及第 3 集的冷开场和说书段（约 −2 LU）。于是按测量结果调了各风格的增益，让每段都回到 v3 原来的位置：

| 风格 | v3 | v3.1 | 原因 |
|---|---|---|---|
| `tension` | 1.45 | 1.30 | 新的 Bass 脉冲让它变响 |
| `epilogue` | 1.25 | 1.02 | 新的长音 Bass 让它变响 |
| `story` | 1.10 | 1.36 | 筝变柔以后变轻 |
| `tease` | 0.95 | 1.15 | 音色变圆以后变轻 |
| `outro` | 1.06 | 1.19 | 同上 |
| `hook`（第 3、4 集） | 1.00 | 1.25 / 1.18（`AU.hookGain`） | 木鱼和高音提示音变柔以后变轻 |

另外，梯顶迷雾一段（`build` 的 `top`）的长音 Bass 从 0.4 降到 0.2，保住“到顶回落”的感觉。

## 3 · 结果

**和旧版比，每个频段变了多少**（两版都标准化到 −16 LUFS，dB；[`tools/_tonal.py`](../../../tools/_tonal.py)）：

| 集 | 31 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
|---|---|---|---|---|---|---|---|---|---|---|
| 第 1 集 | +7.6 | +3.7 | +0.5 | −1.0 | −1.7 | −2.1 | −4.4 | −4.8 | −2.7 | −1.1 |
| 第 2 集 | +8.9 | +3.9 | +0.1 | −0.9 | −1.7 | −2.2 | −3.5 | −4.7 | −3.1 | −1.4 |
| 第 3 集 | +7.1 | +1.4 | +1.6 | −2.1 | −2.5 | −2.9 | −4.2 | −5.2 | −3.5 | −1.6 |
| 第 4 集 | +6.9 | +1.5 | +2.5 | −1.7 | −2.4 | −3.0 | −3.9 | −5.8 | −4.6 | −1.8 |

- 31 Hz 提升 7–9 dB，63–125 Hz 提升 0–4 dB；2–4 kHz 降低 3.5–6 dB。250 Hz–1 kHz 的小幅下降（1–3 dB）是响度标准化带来的：低频多了，其余部分整体让出一点。
- 和参考曲比（第 1 集）：63 Hz–1 kHz 与参考曲中位数相差都在 2 dB 以内，31 Hz 也落在参考曲的范围里（−30 到 −8 dB）；2 kHz 以上比参考曲暗，这是有意的——旧版在这一段本来就不比参考曲亮，却仍然听着刺耳，所以宁可再暗一点。

**响度**（成品 mp4）：

| 集 | 时长 | 整体响度 | 真峰值 | 响度范围 LRA |
|---|---|---|---|---|
| 第 1 集 | 2:49 | −16.1 LUFS（v3 −16.2） | −2.0 dBTP（v3 −1.8） | 5.1 LU（v3 5.0） |
| 第 2 集 | 3:10 | −16.1 LUFS（v3 −16.2） | −1.4 dBTP（v3 −1.6） | 4.2 LU（v3 6.6） |
| 第 3 集 | 3:18 | −16.1 LUFS（v3 −16.3） | −1.4 dBTP（v3 −1.6） | 3.2 LU（v3 4.0） |
| 第 4 集 | 3:33 | −16.1 LUFS（v3 −16.3） | −2.0 dBTP（v3 −1.7） | 2.8 LU（v3 3.7） |

响度范围（LRA）比 v3 略小：持续的 Bass 把最安静的几处托起来了一点，整体更平稳。

**段落之间的平衡**：校准后按配乐段落分别测响度（[`tools/_sections.mjs`](../../../tools/_sections.mjs) 给出段落），四集共 26 段，和 v3 相比每段的变化都在 ±1 LU 以内（−0.7 到 +0.9）。原来的起伏保持不变：序章和尾声比正文轻，冷开场和下集预告更满。

## 4 · 想再调亮 / 调暗

参数都集中在 `src/audio.js` 的几行里：

```js
AU.eq = { music: [...], sfx: [...], voice: [...], verb: [...] };  // 总线 EQ：[类型, Hz, Q, dB]
AU.bass = { sub: 0.6, drive: 3, sat: 1.6, level: 1.0 };          // 次低音、饱和驱动、饱和量、输出
AU.soft = { cut: 0.78, q: 1.6, bell: 0.75, ep: 0.85, ... };       // 配乐音色
AU.voiceTone = { cut: 0.75, q: 1.0 };                              // 角色“叽叽”声
```

- 觉得太闷：把音乐总线的高架从 `['highshelf', 7000, null, -1]` 改成 `['highshelf', 10000, null, 1]`，多一点“空气感”，不会回到刺耳的 2–4 kHz。
- 觉得低频太多（比如用耳机）：`AU.bass.sub` 从 0.6 降到 0.45。

python3 tools/_tonal.py old.wav new.wav             # 两版混音逐频段差值（先都标准化到 −16 LUFS）

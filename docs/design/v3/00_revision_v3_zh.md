# v3 修改说明：《Clawd 造 Clawd》短剧版

v3 在 v2 的 4 集结构上做了两轮修改，四集合计从 **22:20 缩到 12:49**。

## 1 · 两轮反馈

**第一轮：提速、去比喻、缩停顿**
- 节奏太慢，参考 `Harryis666/notion-ai` 仓库 `Skyward/LLM具身Agent视频制作` 分支里的具身智能短片：每段 23–41 秒，每句 3–4.5 秒；**先演反应，再讲原理**；主要原理讲透，次要的一笔带过。
- 能直接讲清原理的地方，不打比方。
- 每集至少砍 1–2 分钟；停顿要短。

**第二轮：做成 Clawd 的短剧**
- “一定要做那种比较吸人眼球、节奏比较快的。至少不能在三秒、五秒内还停留在一个事儿或一个片段上。至少每三五秒钟之后要有个波折。”
- 调研和规则见 `docs/research/05_short_drama_pacing_zh.md`。

## 3 · 第一轮：删了什么、改了什么

**整段删除**
- 第 1 集：“RSI 简史”时间线（1965 → 1987 → 2003 → … → 2026）。保留 I. J. Good 1965 年那句话，它是第 4 集的伏笔。
- 第 3 集：“树上的果子”比喻整场删掉。改为直接说：每升一代，AI 更聪明、研究更快，这是**加速**；容易的先做完了，后面越来越难，这是**阻力**；两者相除就是 r。

**卡片精简**
- 第 2 集：删掉“达尔文-哥德尔机”卡（第 1 级已有 autoresearch 和 AIDE² 两个例子）。
- 第 4 集：“删掉检测标记”一事改写成“会改写自己代码的 AI……”，不再先介绍达尔文-哥德尔机；《自然》2024 的研究从整张卡片改成画面角落的出处说明；OpenAI 的原话缩短。

**比喻改成直接陈述**
- “就像复印件再复印……” → “只用 AI 生成的数据训练下一代，一代代下来，少见的内容最先消失，输出越来越单调。”
- “就像传话游戏……” → “它让目标一代代走样：每次只偏一点点，每一步都看似合理——传上十代，可能面目全非。”
- “先打个比方：把好点子想成树上的果子” → 整段删除（见上）。

**全局节奏参数**（`src/timeline.js`）
- 台词时长：卡片 2.6+字数/8 → 1.8+字数/10.5；旁白 1.2+字数/8.6 → 0.85+字数/10；对白 1.0+字数/7.6 → 0.7+字数/9；最短 2.0 → 1.4 秒。
- 停顿：场景开头 0.7 → 0.3 秒；句间 0.35 → 0.15 秒；场景结尾 1.0 → 0.35 秒。

## 4 · 第二轮：短剧引擎

| 功能 | 做法 | 位置 |
|---|---|---|
| 字幕分页 | 旁白在标点处切成一屏一行（≤ 20 字），翻页带弹跳 | `RSI.splitPages` / `RSI.pagesOf` |
| 花字 | 四集共 156 条关键词大字（`pop` / `stamp` / `tag`），带音效和震屏；超长自动缩小并挪进安全区 | `src/episodes/pops.js`、`RSI.drawPops` |
| 自动推镜头 | 超过 3 秒没有变化的地方，每 ≤ 2.5 秒推 / 拉一次镜头 | `RSI.dramaPrep` / `RSI.camAt` |
| 花字音效 | 新音效 `huazi`（短促的弹响 + 上扬音 + 小铃） | `src/audio.js` |
| 片尾 | 12.5 秒 → 10.2 秒 | `src/scenes/finale.js` |
| 英文版 | 弯引号改成直引号（中文字体会把 ’ 画成全角，比如“Today’ s”） | `RSI.L` |

**结果**：除每集最后的“下集预告”定格外，画面上任意两个变化之间都不超过 3 秒；除片尾字幕外，两条新信息之间不超过 5.2 秒。数据见 `docs/research/05_short_drama_pacing_zh.md` 第 4 节。
